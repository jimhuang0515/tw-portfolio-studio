# 股跡｜台股投資績效 MVP（第一階段）

不需要安裝第三方 Python 套件，內建 SQLite，所有資料預設只存自己的電腦。

## 啟動

1. 安裝 Python 3.10 或更新版本。
2. Windows：在本資料夾點選 `start_windows.bat`。或在終端機執行 `python app.py`。
3. macOS / Linux：執行 `python3 app.py`。
4. 在瀏覽器開啟 **http://127.0.0.1:8765**。

### 建議首次使用流程

1. 先在「出入金」輸入投入證券帳戶的本金，例如 `100000`。提款填負數。
2. 在「新增交易」輸入每筆買進／賣出（以「股」為單位，零股填實際股數）。務必填入實際手續費與交易稅，系統不會自行估算。
3. 按「更新台股行情」，使用 FinMind 的 `TaiwanStockPrice` 日資料更新歷史收盤價，或手動輸入股價。
4. 如需匯入多筆交易，下載 CSV 範本並依欄位整理。CSV 的欄位為 `date,symbol,name,side,qty,price,fee,tax,note`，`side` 使用 `BUY`、`SELL`；同一天的交易依 CSV 原有列順序處理。

## 功能

- 現股交易新增／刪除，平均成本法與賣超防呆。
- 手續費、交易稅、已實現損益、未實現損益、持股市值、現金、淨值。
- 交易日期與日收盤價資料、淨值時間序列、最新有效淨值差額。
- 可匯入券商 CSV 整理後的標準格式（不是直接支援所有券商原生 CSV）。
- FinMind 盤後歷史股價更新（可選環境變數 `FINMIND_TOKEN`）。
- 手動股價備援。

## 注意事項：績效定義與限制

- **累積淨損益**＝目前淨值－淨入金，包含已實現／未實現損益，交易成本會計入。
- **累積報酬率**＝累積淨損益／淨入金，這是簡單計算，**不是 TWR 或 XIRR**；期間有多次入金或提款時不能直接拿來與大盤績效比較。
- **最新交易日損益**＝最近兩個可用淨值日期差額扣除當日出入金，非必然是「今天」的損益；畫面會顯示資料截至日期。
- **單日報酬率**＝最近兩筆淨值差額扣除當日現金流，除以前筆淨值，同日入金或提款時為近似值。非每日都有行情時，該筆可能跨數個交易日。
- 只支援台幣、多頭現股；不支援融資、融券、期權、拆股、減資、配股、股息、外幣、現金利息。
- 股價資料是**未還原收盤價**，除權息／分割事件需後續處理，避免誤判績效。
- 有任何持股缺乏可用股價時，歷史圖會跳過該日期；首頁也會顯示警告。缺價時市值與淨值不完整。
- 僅更新到 FinMind 已發布的資料日，不保證盤中更新。免費 API 有流量與授權限制，請參考 https://finmind.github.io/quickstart/ 。
- 目前沒有登入權限管理，**僅在本機 127.0.0.1 開放**，請勿直接對外網路公開。
- `portfolio.sqlite3` 是你的資料，請定期備份。刪除該檔會失去紀錄。
